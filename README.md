💧 Smart Water Pump Simulator

An interactive 3D Water Pump Simulator designed to demonstrate automated water supply management, tank-level monitoring, motor operation, and system fault detection.

🚀 About the Project

The Smart Water Pump Simulator is a web-based educational project that simulates an automated water pumping system. It provides a visual representation of water levels, pump operation, and system conditions through an interactive interface.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js (3D visualization)

✨ Features

- Interactive 3D water pump simulation
- Underground and overhead water tank visualization
- Water-level monitoring
- Pump and motor control
- Real-time system status monitoring
- Fault detection and warning alerts
- Audible alarm for active faults
- User-friendly control panel

📸 Project Preview

Open the simulator in your browser to explore its interactive interface.

▶️ How to Run

1. Download or clone this repository.
2. Extract the project folder if downloaded as a ZIP.
3. Open the project folder in Visual Studio Code.
4. Run "index.html" using Live Server.
5. Interact with the simulator through the control panel.

🎯 Project Objective

To demonstrate the working principles of an automated water pumping system through an interactive web-based simulation.
